Kịch bản A · TCP SYN Flood (Direct)

Bắn gói tin TCP SYN từ IP thật của laptop này vào cổng 80, tạo kết nối nửa mở (half-open) làm cạn kiệt bảng SYN backlog.

#B

Kịch bản B · TCP SYN Spoofing

Bắn gói tin SYN với địa chỉ IP nguồn ngẫu nhiên hoàn toàn (--rand-source), giả lập botnet phân tán khổng lồ (Entropy H(src) > 10).

L7 Application DDoS L7 Paced HTTP
#C

Kịch bản C · HTTP Flood (Paced)

Bắn các yêu cầu HTTP GET hợp lệ có kiểm soát nhịp độ (paced) với 20 luồng đồng thời, cạn kiệt worker pool Nginx (ACK >> SYN).

L4 Transport Volumetric hping3 UDP
#U

Kịch bản U · UDP Volumetric Flood

Bão gói tin UDP flood nhắm vào cổng 80, làm nghẽn băng thông và tiêu hao tài nguyên xử lý gói tầng L4 của nạn nhân.

L3 Network Ping Flood hping3 ICMP
#I

Kịch bản I · ICMP Echo Ping Flood

Tạo bão gói tin ICMP echo-request liên tục (hping3 --icmp) làm quá tải stack mạng hạt nhân Linux của máy Victim.
